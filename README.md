# 🎉 Holiday Bot — Telegram бот с праздниками

Telegram-бот, который каждый день присылает подписчикам праздники дня.  
Использует **Google Gemini 1.5 Flash** (бесплатный план) для живых и интересных описаний.

---

## 🚀 Быстрый старт

### 1. Получить токены

#### Telegram Bot Token
1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Команда `/newbot` → задайте имя и username
3. Скопируйте токен вида `123456:ABC-DEF...`

#### Google Gemini API Key (бесплатно!)
1. Перейдите на [aistudio.google.com](https://aistudio.google.com)
2. Войдите через Google аккаунт
3. Нажмите **Get API Key** → **Create API key**
4. Скопируйте ключ

> ✅ Бесплатный план Gemini: 15 запросов/минуту, 1500/день — более чем достаточно!

---

### 2. Установка и запуск

#### Вариант А: Python напрямую

```bash
# Клонируйте / распакуйте файлы бота
cd holiday_bot

# Установите зависимости
pip install -r requirements.txt

# Задайте переменные окружения
export BOT_TOKEN="ваш_токен_бота"
export GEMINI_API_KEY="ваш_ключ_gemini"

# (Опционально) Время рассылки (по умолчанию 09:00 МСК)
export SEND_HOUR=9
export SEND_MINUTE=0

# Запустите бота
python bot.py
```

#### Вариант Б: Docker

```bash
# Создайте файл .env
echo "BOT_TOKEN=ваш_токен_бота" > .env
echo "GEMINI_API_KEY=ваш_ключ_gemini" >> .env

# Запустите
docker-compose up -d
```

## 📁 Форматы файлов с праздниками

Бот поддерживает три формата. Дата всегда в формате `ДД.ММ`.

### TXT (самый простой)
```
01.01 - Новый год
14.02 - День святого Валентина
08.03 - Международный женский день
# Строки с # — комментарии
```
Поддерживаемые разделители: ` - `, ` – `, ` — `, `\t`, `: `, ` | `

### CSV
```csv
дата,праздник
01.01,Новый год
25.12,Рождество
```

### JSON
```json
{
  "01.01": ["Новый год"],
  "14.02": ["День Валентина", "День программиста влюблённых"]
}
```

## ⚙️ Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `BOT_TOKEN` | Токен Telegram бота | — (обязательно) |
| `GEMINI_API_KEY` | Ключ Google Gemini API | — (обязательно) |
| `SEND_HOUR` | Час рассылки (МСК) | `9` |
| `SEND_MINUTE` | Минуты рассылки (МСК) | `0` |

## 📦 Зависимости

- **aiogram 3** — современный async фреймворк для Telegram Bot API
- **APScheduler** — планировщик ежедневных рассылок
- **google-generativeai** — официальный SDK для Gemini API

---

## 💡 Советы

- Бот хранит данные в двух JSON файлах: `subscribers.json` (подписчики) и `holidays.json` (праздники)
- При запуске через Docker смонтируйте папку `./data` для сохранения данных между перезапусками
- Время рассылки — московское (Europe/Moscow)
- Файлы с праздниками накапливаются: каждый новый файл добавляет праздники к уже существующим
